# 💻 Relayt
An open-source client for your AI API, built with React, Tailwind CSS, and Vite. The website is hosted on Vercel, while the Android application is powered by Capacitor

## 🔒 Security
Relayt does not collect any user data, including API keys, chats, or conversations with AI models

All your data is stored exclusively in your own environment:

- With your API provider
- In your browser's local storage
- On your own VPS
- In your cloud storage (WebDAV)
- In Supabase (if you have configured any of these services for synchronization)

## 📋 Instructions
### 1. How to connect an AI model?

- Go to `Settings → API & Speed Dial`
- Enter your API key in the designated field (OpenRouter, Claude, Gemini, or the ChatGPT API are recommended)
- Add a model to your Speed Dial

You can add up to 5 models to Speed Dial and switch between them directly in your chat

### 2. How to enable Web Search?

- Go to `Settings → Web Search`
- Add an API key from one of the supported providers:

  - Tavily
  - Brave Search API
  - Serper.dev
  - Exa

**Recommendation:** Add all four providers. This way, if you run out of free credits with one provider, you can seamlessly switch to another
